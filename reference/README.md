# Book — полезные идеи из старых веток

Эта ветка создана специально как **нейтральная библиотека полезных материалов**.

Она создана от текущего `main` 22.09.2026.

## Главное правило

Здесь **не хранится старый production-код для будущего merge**.

Старые `fix`, `hotfix`, `recovery`, миграции и юридические реализации сюда специально не переносятся.

Если какая-то идея понадобится, её надо реализовывать заново от актуального `main`.

## Что сохранено

### 1. UI Reference V2

Файл:
`reference/UI_REFERENCE_V2_DRAFT.md`

Источник:
`docs/ui-reference-v2-draft-20260922`

`reference/NOTIFICATIONS_REMINDERS_IDEA.md`

## Что намеренно НЕ сохранено

### Старые юридические контуры

Не сохраняются старые реализации из веток:
- `feature/legal-*`;
- `feature/messages-consent-*`;
- старые `pdn` / `consent` cleanup/fix;
- `archive/staging-before-legal-rebuild-2026-09-18`.

Причина: текущий `main` является источником истины. Старые варианты содержали более жёсткие/другие блокировки и не должны случайно вернуться.

### Старые миграции, recovery, hotfix, promote/promotion

Не сохраняются как полезные материалы.

Это техническая история ремонта и доставки, а не продуктовая библиотека.

### Финансы

Старые finance-ветки не копируются, потому что текущий `main` уже содержит более позднюю архитектуру и реализацию. Старые варианты не надо держать как конкурирующий источник истины.

### Documents / Archive

Старые архитектуры документов не копируются.
Текущий `main` содержит более новую схему `DocumentArchive / PlatformDocumentArchive / TenantDocumentArchive`.

### Старые нейминги / People / Profile

Не копируются, если их смысл уже отражён в актуальных словарях `main`.

## Для чего нужна эта ветка

Чтобы после очистки GitHub можно было оставить только:

- `main`;
- `staging`;
- `reference/useful-ideas-20260922`.

И при этом не потерять хорошие незавершённые задумки.
