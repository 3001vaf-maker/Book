# Полезные идеи: Telegram-вход

> Источники:
> - `feat/telegram-main-miniapp`
> - `feat/telegram-passwordless-client-auth`
>
> Старый код не сохраняется. Ниже только идеи, которые могут понадобиться позже.

## 1. Telegram Mini App как точка входа

Ранее обсуждалась/реализовывалась возможность открывать Book или клиентский контур из Telegram Mini App.

Полезная идея:
- Telegram может быть удобной внешней точкой входа;
- при этом сам Book остаётся самостоятельным приложением и не должен зависеть от Telegram.

## 2. Вход клиента без пароля через Telegram

Была отдельная идея passwordless-входа клиента через подтверждённую Telegram-сессию.

Смысл:
- если Telegram уже надёжно подтвердил пользователя, не заставлять его дополнительно вводить пароль;
- связь должна быть с каноническим Account/Profile текущей архитектуры;
- нельзя возвращать старые Client/UEI-костыли или параллельную систему идентичности.

## Перед возвратом идеи

Обязательно заново проверить:
- текущую модель Account / Profile / Person;
- действующие согласия;
- current client booking flow;
- безопасность Telegram init data;
- отсутствие второй параллельной авторизации.
