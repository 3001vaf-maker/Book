# Реализация durable capability onboarding

Этот файл фиксирует техническую границу реализации.

- Состояние выдачи/отзыва и ознакомления хранится на сервере.
- Браузерное хранилище не является источником истины для onboarding возможностей.
- Полная перезагрузка страницы не требуется для применения изменения.
- Общий модал изменения доступа блокирует работу до подтверждения.
- Для выданной BOOLEAN-возможности отдельное объяснение показывается при первом входе именно в эту возможность.
- Для отозванной возможности UI скрывается при обновлении runtime access, а серверное событие сообщает об отзыве.
- Черновые тексты находятся в capability registry и должны быть отредактированы отдельно без изменения механизма.
