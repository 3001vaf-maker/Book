# TODO — тексты объяснений возможностей

Механизм выдачи/отзыва и обязательного знакомства реализуется отдельно от финальной редакции текстов.

Перед широким запуском нужно пройти по каждой BOOLEAN-capability и утвердить:

- заголовок общего/индивидуального сообщения;
- 1–2 коротких предложения «что теперь можно»;
- первое рекомендуемое действие;
- текст основной кнопки;
- формулировку сообщения при отзыве, если для конкретной возможности нужна не общая формула.

Текущие тексты в `core/capability-registry.js` считаются черновыми и служат только для проверки механики.
