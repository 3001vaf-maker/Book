# Онлайн-запись — архитектура экранов Book

Раздел строится на общем Book shell из `docs/BOOK_SHELL.md`.

## 1. Онлайн-запись

- A: Назад в Настройки.
- J: Онлайн-запись.
- B: отсутствует.
- C: открывает compact modal с папками.
- S: скрыто.
- V: только ссылки.

В V находятся:
- Общая ссылка.
- Select рабочего пространства.
- Ссылка выбранного рабочего пространства.

C открывает обычный лист из трёх папок:
- Приветствие.
- Внешний вид.
- Время записи.

## 2. Приветствие

- A: Назад в Онлайн-запись.
- J: Приветствие.
- B: Сохранить; появляется только после изменения.
- C: отсутствует.
- S: скрыто.

V:
- Заголовок.
- Текст.

## 3. Внешний вид

- A: Назад в Онлайн-запись.
- J: Внешний вид.
- B: Сохранить; появляется только после изменения.
- C: действия текущего экрана.
- S: скрыто.

V:
- Иконка информации; поясняющий текст открывается в compact modal.
- Select фона: однотонный / градиент.
- Одна парная строка: Цвет фона / Второй цвет фона.
- Одна парная строка: Тёмный цвет / Светлый цвет.
- Select формы элементов.
- Select вида выбора.
- Предпросмотр.

C открывает две кнопки одинакового уровня:
- Отменить — вернуть последнее сохранённое состояние.
- Сбросить — подставить стандартный дизайн Book в черновик.

Обе кнопки белые с коричневым контуром. Сброс не сохраняется автоматически: после него появляется B = Сохранить.

## 4. Время записи

- A: Назад в Онлайн-запись.
- J: Время записи.
- B: Сохранить; появляется только после изменения.
- C: отсутствует.
- S: скрыто.

V:
- Select «Шаг доступного времени» со значениями 5, 10, 15, 30 минут и 1 час.
- Краткое пояснение о том, что шаг влияет на доступные начала записи, но не меняет длительность процедур.

## Общие правила

- Несохранённые изменения являются черновиком.
- Переход Назад без сохранения возвращает к родительскому экрану и не сохраняет черновик.
- Настройки сохраняются только через B = Сохранить.
- Нижнее меню D/X/F/Z/Y остаётся общим меню Book и не дублируется внутри раздела.
