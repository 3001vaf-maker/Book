# Онлайн-запись — архитектура настроек

## F6-E «Онлайн-запись»

Отдельной E «Уведомления» нет. Настройки событий онлайн-записи принадлежат самой онлайн-записи. Сообщения, группы и шаблоны принадлежат Чату.

## Z1 «Онлайн-запись»

- A: профиль / настройки онлайн-записи.
- B: «Онлайн-запись».
- C: отсутствует.
- D: общий Чат.
- Z1:
  - общая ссылка + Shared copy;
  - Shared Select рабочего пространства;
  - ссылка выбранного рабочего пространства + Shared copy;
  - Shared Select «Шаг записи» + [i].

Изменение шага сохраняется сразу. [i] открывает техническую информацию. Шаг задаёт удобную сетку начал записи и не ограничивает произвольное время специалиста.

## A1 «Настройки онлайн-записи»

Shared нижний X содержит только:
- «Приветствие»;
- «Настройки уведомлений».

Старая настройка «Внешний вид» удалена. Публичная онлайн-запись использует единый дизайн приложения.

## Q «Приветствие»

Q перекрывает активный Z и после смахивания возвращает ровно на поверхность, из которой был открыт.

- B: «Приветствие».
- C: «Сохранить» только после изменения.
- D: скрыт.
- Поля:
  - «Заголовок»;
  - «Текст».

Локальной кнопки «Сохранить» внутри Q нет.

## X «Настройки уведомлений»

Shared нижний form-sheet:
- Push + [i] с пояснением его роли;
- «Порядок отправки»:
  - «Во все выбранные каналы»;
  - «По очереди, если предыдущий не доставлен»;
- «Канал 1»;
- «Канал 2»;
- «Канал 3»;
- «Сохранить».

В каждом выборе порядок вариантов:
1. Push;
2. Telegram;
3. Email;
4. Не использовать.

Push выбираемый, а не обязательный. В последовательном режиме Push является дополнительным уведомлением и не завершает цепочку. Успешную последовательную доставку определяют Telegram / Email.
