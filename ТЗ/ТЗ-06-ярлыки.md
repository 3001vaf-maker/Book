# ТЗ-06 — Ярлыки

## 1. Назначение

Добавить в существующее приложение Book новую сущность **«Ярлык»**.

Каждый созданный ярлык является экземпляром одной сущности.

**Каждое последующее ТЗ продолжает существующую реализацию Book и не изменяет, не переписывает и не нарушает ранее реализованные архитектуру, сущности и принятые решения, если это прямо не указано в новом ТЗ.**

---

## 2. Расположение

В существующей структуре приложения:

```text
Настройки
└── Ярлыки
```

Используется существующая папка/ветка `Ярлыки`.

Новую параллельную ветку создавать нельзя.

---

## 3. Список ярлыков

При входе в:

**Настройки → Ярлыки**

открывается список ярлыков.

При первоначальном открытии список **пустой**.

Заголовок:

**Ярлыки** `[ + ]`

После создания нового ярлыка он появляется в этом списке.

Пример:

```text
Ярлыки                              [+]

Клиент VIP                         [X]
Окрашивание                        [X]
Постоянный                         [X]
```

Справа от каждого ярлыка находится существующий в приложении значок удаления **[X]**.

Новый значок удаления создавать нельзя.

---

## 4. Создание ярлыка

При нажатии `[ + ]` открывается существующее стандартное модальное окно Book.

Содержание:

```text
Новый ярлык                         [ X ]

[ Выбор цвета ]

Название ярлыка
[________________________]

[ Сохранить ]
```

### Цвет

Вместо фотографии используется **выбор цвета ярлыка**.

Выбор цвета открывается в модальном окне.

Модальное окно выбора цвета должно соответствовать визуалу существующего приложения Book.

Не использовать технический/системный интерфейс выбора цвета, который визуально выбивается из приложения.

Выбранный цвет сохраняется вместе с ярлыком.

### Название

Название ярлыка является обязательным.

Без названия ярлык не создаётся.

### Сохранить

После сохранения новый ярлык появляется в списке.

### X

При нажатии `[ X ]` модальное окно закрывается без создания ярлыка.

---

## 5. Отображение ярлыка в списке

После создания ярлык отображается непосредственно в списке.

Карточка для ярлыка **не создаётся**.

Отдельный экран/карточка ярлыка **не создаётся**.

При создании ярлыка пользователь видит только то, что список пополнился новым ярлыком.

Справа от ярлыка отображается существующий общий значок удаления **[X]**.

Цвет ярлыка используется в его визуальном представлении согласно существующей UI-системе.

---

## 6. Удаление

Для каждого ярлыка используется существующий значок удаления **[X]**, уже применяемый в приложении.

Новый компонент удаления не создавать.

При нажатии на `[X]` соответствующий ярлык удаляется из списка.

---

## 7. Граница текущего ТЗ

В рамках этого ТЗ реализуются только:

- контейнер `Ярлыки`;
- пустой начальный список;
- создание ярлыка;
- обязательное название;
- выбор цвета;
- сохранение ярлыка;
- отображение ярлыка в списке;
- удаление существующим механизмом.

**Карточки ярлыков не создаются.**

**Отдельная бизнес-логика применения ярлыков к другим сущностям в это ТЗ не входит.**
