# Book — архитектурный словарь

## Назначение

Единый словарь архитектуры проекта Book. Используется вместе с `DESIGN_DICTIONARY.md`.

## 1. Структура приложения

| English | Русский | Значение |
|---|---|---|
| FOLDER | Папка | Структурный раздел приложения. Может содержать другие папки и данные. |
| DATA | Данные | Информация, принадлежащая конкретной папке. |
| FOLDER CONTROLLER | Управление папкой | Код, отвечающий за работу конкретной папки. |

**Правило:** Папка ≠ UI-компонент. Папка ≠ модуль.

Термин `MODULE / МОДУЛЬ` не используется как альтернативное название структурной папки.

## 7. Ответственность

```text
CORE
└── центральное управление

FOLDER
└── структурная единица приложения
    └── FOLDER CONTROLLER
        └── управление этой папкой

UI
└── единые визуальные компоненты и их стандартное UI-поведение

DESIGN DICTIONARY
└── утверждённые визуальные правила

STYLES.CSS
└── единый источник CSS-реализации
```

## 8. Правило единственного источника

Одна сущность — одно имя — одно место ответственности.

Один UI-компонент имеет одну реализацию во всём приложении. Функциональные папки используют общий UI и не создают собственные копии компонентов.

Варианты одного компонента реализуются через `variant`, а не через дубликат компонента.

Пример:

```text
FOLDER
├── default — обычная папка
└── feature — большая папка
```

Нельзя создавать отдельные `FeatureButton`, если визуально это вариант папки.

## 9. Разделение управления и отображения

UI не определяет бизнес-структуру приложения.

Поток должен быть однозначным:

```text
CORE
  ↓
команда / действие
  ↓
FOLDER CONTROLLER
  ↓
данные + состояние
  ↓
UI COMPONENT
  ↓
отображение
```

Папка передаёт UI данные и состояние. UI не получает самостоятельного права менять структуру приложения.

## 10. Единый дизайн

Все UI-компоненты используют единые правила из `DESIGN_DICTIONARY.md`.

Цвета, типографика, отступы, радиусы, размеры, иконки и состояния не переопределяются локально в функциональных папках без отдельного архитектурного решения.

## 11. Запрет терминологической путаницы

Не использовать «Модуль Сервис», «Модуль Профиль», «Модуль Настройки», если имеется в виду структурная папка.

Использовать:

```text
Папка Сервис
Папка Профиль
Папка Настройки
```

`MODULE` может использоваться только если в будущем будет отдельно введено техническое понятие модуля. До такого решения термин не используется.
