# Book — архитектурный словарь

Этот документ фиксирует единый словарь терминов проекта Book.

## 1. Структура приложения

| English | Русский | Значение |
|---|---|---|
| FOLDER | Папка | Структурный раздел приложения. Может содержать другие папки и данные. |
| DATA | Данные | Информация, принадлежащая конкретной папке. |
| FOLDER CONTROLLER | Управление папкой | Код, отвечающий за работу конкретной папки. |

**Правило:** Папка ≠ UI-компонент. Папка ≠ модуль.

Термин MODULE / МОДУЛЬ не используется как название структурной папки приложения.

## 3. UI-навигация

| English | Русский | Значение |
|---|---|---|
| NAVIGATION | Навигация | Перемещение между разделами. |
| BOTTOM NAVIGATION | Нижняя навигация | Нижнее меню приложения. |
| PAGE HEADER | Заголовок страницы | Верхняя область экрана. |

**Правило BACK:** кнопка «Назад» возвращает на один шаг назад в предыдущую папку и не перескакивает самостоятельно в Журнал, Главную или другой раздел.

## 7. Основные архитектурные правила

1. Одна сущность — одно имя — одно место ответственности.
2. Один UI-компонент имеет одну реализацию во всём приложении.
3. Папки используют UI-компоненты; они не создают собственные копии.
4. Варианты одного компонента реализуются через вариант (variant), а не через дубликат компонента.
5. UI отвечает за отображение и стандартное UI-поведение.
6. Core отвечает за центральное управление и передачу команд.
7. Управление конкретной папкой находится в её собственном контроллере.
8. Единый внешний вид задаётся общей UI-системой и единым источником CSS.
9. MODULE / МОДУЛЬ не используется как альтернативное название FOLDER / ПАПКА.
